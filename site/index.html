01. Features

What it does

Three commands: kaskade admin for topics and consumer groups, kaskade consumer to read records, and kaskade producer to write them.

kaskade admin

Manage topics

  • Topics, partitions, consumer groups, lag, replicas, and record counts
  • Create, edit, delete, and filter topics, and check their configuration
  • Refresh every 30 seconds by default, or whenever you ask

kaskade consumer

Read records

  • Start from the latest or earliest offsets, or exact partitions and offsets
  • Decode JSON, Avro, and Protobuf, with local schemas or Schema Registry
  • Filter by key, value, header, or partition
  • See records that fail to decode as bytes next to the error

kaskade producer

Write records

  • Compose a key, value, and headers, and see the offset the broker acknowledged
  • Encode the consumer's formats, validate JSON Schema, and register schemas
  • Resend a record copied from the consumer, or load a draft from a file

Every mode client.ini · TLS · SASL · Confluent Cloud · Amazon MSK IAM · themes · keybindings · copy and export

03. Install

Quick start

Install with Homebrew or pipx, then point Kaskade at a broker or a client.ini file.

Option A

Homebrew

brew
$ brew install kaskade

Option B

pipx

pipx
$ pipx install kaskade
Then connect

Replace the example broker, topic, and options with your own.

Admin $ kaskade admin -b my-kafka:9092
Consumer $ kaskade consumer -b my-kafka:9092 -t my-topic
Producer $ kaskade producer -b my-kafka:9092 -t my-topic
Config file $ kaskade admin --config-file client.ini
