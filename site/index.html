Kaskade: Kafka in your terminal

Kaskade

A terminal UI for Kafka with three modes: manage topics and consumer groups, read records, and produce them, as JSON, Avro, or Protobuf, with or without Schema Registry. Everything works from the keyboard.

install
$ brew install kaskade
$ pipx install kaskade

latest release on GitHub

For macOS and Linux, with Python 3.10 or later.

Read a topic

Start the consumer on a topic, move through the records with the arrow keys or j and k, and press Enter to open a record.

Three modes

  • Admin

    Browse topics, partitions, consumer groups, lag, and record counts. Create, edit, and delete topics, and check their configuration.

    kaskade admin -b my-kafka:9092

  • Consumer

    Read from the latest or earliest offsets, or from exact partitions. Decode JSON, Avro, and Protobuf, filter records, and copy or export them.

    kaskade consumer -b my-kafka:9092 -t my-topic

  • Producer

    Compose a key, value, and headers, encode them in the consumer's formats, and see the offset the broker acknowledged.

    kaskade producer -b my-kafka:9092 -t my-topic

Every mode reads the same client.ini and supports TLS, SASL, Confluent Cloud, Amazon MSK IAM, themes, and custom keybindings. The usage guide covers each option.
